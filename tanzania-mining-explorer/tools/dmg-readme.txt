Ngao Exploration Console.app
    Double-click to launch. The console opens in your default browser —
    it is a single self-contained file and works fully offline.

    First launch on macOS: this app is not notarised with Apple, so
    macOS will warn about an unidentified developer. Right-click
    (or Control-click) the app, choose "Open", then confirm.
    On macOS 15 (Sequoia) and later: if there is no "Open" override,
    launch it once, then allow it under
    System Settings > Privacy & Security > "Open Anyway".

    You can also open the console with no app at all: right-click the
    app > Show Package Contents > Contents > Resources > index.html,
    and open that file in any browser.

Demo (1 minute).mp4
    A narrated one-minute walkthrough of the console.

Google Maps satellite imagery is optional: choose "Google Satellite"
in the console and paste a Maps JavaScript API key. Without one, the
console uses its own built-in Tanzania basemap.

Note: the geography, belts and infrastructure are real; licence
numbers, holders, assays, crews and laboratory queues are synthetic.
This is a technology demonstrator, not a feed from the Mining Cadastre.
